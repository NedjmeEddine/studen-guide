# Student Guide

Interactive high-density STEM revision sheets, cheat sheets, 3D math & science visualizers, formula references, and active recall practice.

## Overview
Student Guide parses rich academic Markdown study sheets with:
- **Interactive domain embeds**: 2D/3D math plots, SPICE circuit netlists, parametric ECG telemetry, odontograms, chemical SMILES, state machines, and sequence diagrams
- **Active recall study tools**: interactive self-checking quizzes, collapsible flashcards, and completion checklists
- **Theme Studio & Ricing**: multiple academic themes (Paper, Dark/GitHub, Cyberpunk, Forest, Rose-Pine, Solarized) plus in-app custom CSS dotfile styling
- **Print & Export**: clean single/multi-page print CSS removing interactive controls for pure course summary exports
- **AI Skills Hub**: 1-click prompt generator to author custom study sheets and themes with LLMs

Built with React 19, TanStack Start / Router, Vite, Tailwind CSS 4, and Nitro for Cloudflare deployment.
